# WorldAI

**WorldAI** is the short name for WorldArchitect.AI. It is also the name you actually see while playing: the wordmark in the top-left of the site reads **WorldAI**, the browser tab says WorldAI, and the dashboard asks "New to WorldAI?". You will meet it in this wiki's plumbing too — the repository is `worldai_wiki`, and the first-session guide lives at [how-to-play-worldai.md](../queries/how-to-play-worldai.md) — but page text here spells the name out in full. It is the same game at [worldarchitect.ai](https://worldarchitect.ai); there is no separate product.

See [WorldArchitect](WorldArchitect.md) for what the game is and does.
