# WorldAI

**WorldAI** is the short name for WorldArchitect.AI. You will still meet it in this wiki's own plumbing — the repository is `worldai_wiki`, and the first-session guide lives at [how-to-play-worldai.md](../queries/how-to-play-worldai.md) — but page text spells the name out in full. It is the same game at [worldarchitect.ai](https://worldarchitect.ai); there is no separate product.

See [WorldArchitect](WorldArchitect.md) for what the game is and does.
